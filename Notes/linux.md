# 🐧 Шпаргалка по базовым командам Linux

## 1. Навигация и работа с файлами

- `pwd` — выводит текущую рабочую директорию.
- `ls -la` — список всех файлов и папок (включая скрытые) с правами и размерами.
- `cd /path/to/dir` — переход в указанную директорию (`cd ..` — на уровень вверх).
- `mkdir -p path/to/dir` — создание директории (флаг `-p` создает вложенные папки).
- `touch file.txt` — создание пустого файла или обновление времени модификации.
- `cat file.txt` — просмотр всего содержимого файла.
- `less file.txt` — постраничный просмотр файла (выход по клавише `q`).
- `rm -rf dir/` — рекурсивное удаление папки без подтверждения (**использовать с осторожностью**).

## 2. Поиск и логи

- `grep -r "SEARCH_TEXT" ./` — рекурсивный поиск текста во всех файлах текущей папки.
- `tail -f /var/log/syslog` — просмотр новых строк файла логов в реальном времени.
- `tail -n 50 app.log` — вывод последних 50 строк файла.

## 3. Процессы и системные ресурсы

- `ps aux` — полный список всех запущенных процессов в системе.
- `top` / `htop` — интерактивный мониторинг загрузки CPU, RAM и процессов.
- `df -h` — информация об использовании дискового пространства в понятном формате (Gb/Mb).
- `du -sh ./` — суммарный объем, занимаемый текущей папкой.

## 4. Права доступа и переменные окружения

- `chmod +x script.sh` — делает файл исполняемым.
- `chmod 700 ~/.ssh` — доступ только владельцу (rwx).
- `chmod 600 ~/.ssh/id_ed25519` — чтение/запись только владельцу.
- `env` — список всех переменных окружения.
- `export MY_VAR="value"` — установка переменной окружения в текущей сессии bash.

## 5. Пайпы и перенаправление потоков

- `command > file.txt` — перенаправление вывода (stdout) в файл (перезапись).
- `command >> file.txt` — добавление вывода в конец файла (append).
- `command 2>&1` — перенаправление ошибок (stderr) в стандартный вывод (stdout).
- `ps aux | grep python` — передача вывода первой команды на вход второй через пайп (`|`).

---

## 🔒 Безопасность SSH

- Права на `~/.ssh` (`700` / `drwx------`): гарантируют, что только владелец может читать содержимое SSH-каталога.
- Права на приватный ключ (`600` / `-rw-------`): SSH-клиент блокирует использование ключей, если права открыты для
  других пользователей.
